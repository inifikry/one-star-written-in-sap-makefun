# One Star, Written in Sap

A one-line 1-star review written by a houseplant about the human who owns it, for the [make.fun](https://make.fun/c/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) bounty "One Star, Written in Sap".

## The line

> One star. He bought me for the aesthetic, named me after his ex, and waters me as often as he calls his mother: never. I now photosynthesize purely out of spite.

## Run

```sh
python3 main.py
```

Writes the review to `/output/entry.txt` — one line, under 280 characters, UTF-8.
